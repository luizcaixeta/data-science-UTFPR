# Projeto: Análise de dados SiGesGuarda

## Equipe: Data BIT

## Descrição: 

Este trabalho realiza uma análise exploratória dos dados do Sistema Integrado de Gestão da Guarda Municipal de Curitiba (SiGesGuarda), com o objetivo de identificar padrões espaciais, temporais e operacionais nas ocorrências registradas. A partir dessas análises, busca-se compreender a distribuição e a natureza dos atendimentos, bem como suas relações com diferentes regiões e contextos da cidade. Além disso, propõe-se o desenvolvimento de um modelo de classificação para prever o tipo de ocorrência com base nas variáveis disponíveis, gerando insights que possama apoiar a tomada de decisão e contribuir para a melhoria da gestão da segurança pública.
